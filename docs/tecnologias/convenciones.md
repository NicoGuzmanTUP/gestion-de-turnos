# Convenciones técnicas

Referencia rápida de criterios acordados para mantener consistencia entre ambos desarrolladores. Se va completando a medida que surgen decisiones — no hace falta detalle extenso, alcanza con dejar asentado el criterio.

## Idiomas

- **Código (nombres de variables, funciones, clases, endpoints, etc.):** inglés.
- **Comentarios en el código:** español.
- **Mensajes de error de cara al cliente (frontend, respuestas de API visibles para el usuario):** español.

## Pendiente de definir

- Convención de nombres de ramas (branches).
- Formato de mensajes de commit.
- Estilo/formato de código (linter, formatter) por proyecto (backend / frontend).
- Convención de nombres de endpoints REST.
- Manejo de logs (idioma, nivel, formato).
